# 福岡市 財政・人口データ取得スキル（福岡市オープンデータ CKAN）

福岡市（団体コード `40130`）の財政・人口データは **福岡市オープンデータ（CKAN）** の CSV から取得する。
公式・単一ソース・最新（令和5年度=2023）まで・経年10年が揃う。

> このskillがあれば、データセットの再探索なしに取得元・CSV項目・手順が分かる。

## CKAN（データカタログ）
- カタログ: `https://ckan.open-governmentdata.org/`（福岡市。2025年にBODIK ODCSへ移行したが旧CKAN APIは現行で稼働）
- API（JSON, 機械可読）:
  - データセット検索: `https://ckan.open-governmentdata.org/api/3/action/package_search?q=<語>&fq=organization:fukuoka&rows=10`
  - データセット詳細（リソースURL一覧）: `https://ckan.open-governmentdata.org/api/3/action/package_show?id=<dataset-name>`
- CSV はリソースの `url`（`.../download/xxx.csv`）から直接DL。**encoding は `utf-8-sig` または `cp932`**（自治体CSVはcp932が多い）。多くは「1行目=年度ヘッダ／1列目=項目名」の横持ち。

## 主要データセット（確認済み）

### 1. 財政状況の推移（本ページの主データ）
- dataset id: **`zaiseijoukyou-no-suii`**（タイトル: 福岡市財政状況の推移）
- リソース3本（CSV）: 「一般会計」「歳入」「歳出目的別」
- 期間: **平成26〜令和5年度（2014〜2023年度）10年分**（横持ち：列=年度）
- 歳出目的別の費目: **民生費 / 衛生費 / 土木費 / 教育費 / 総務費 / 公債費 / 商工費 / その他 / 合計 / 一般会計歳出合計**
- 用途: 収入構造の推移・歳出の重点の推移（設計の中核）

### 2. 決算（単年の細目）
- 「決算」データセット（検索 `q=決算&fq=organization:fukuoka`）に **一般会計決算（款別）/ 歳出決算（目的別）/ 歳出決算（性質別）** のCSV。年度ごとの細かい内訳が要るとき使う。

### 3. 人口
- `jinkou-nenpou`（福岡市の推計人口・年報, CSV/PDF）★1人あたり換算・人口推移の主データ
- `juuki-jinkou`（住民基本台帳人口・世帯数, CSV）
- `kokusei-chousa`（国勢調査, CSV）/ `kouku-jinkou`（校区別人口）/ `suikei-jinkou-geppou`（推計人口・月報）

## 取得手順
1. `package_show?id=<dataset>` で各 CSV リソースの `url` を取得。
2. CSV を直接DL（cp932/utf-8-sig でデコード）。
3. 横持ち（年度×項目）を縦持ちに整形し、必要項目（歳出費目・歳入財源・総額・人口）を抽出。
4. 更新スクリプトで取得→整形JSONを `data/` に同梱（ランタイムで外部依存させない）。年1回更新。

## 出典・利用規約
- 出典表記: **「出典: 福岡市オープンデータ」**（データセット名・年度を併記）。福岡市オープンデータ（CC等）の利用条件に従う。公式・一次データのため二次利用の懸念は小さい。

## 環境の注意（このリポジトリ／Claude Code）
- **外部HTTP取得は Bash の `dangerouslyDisableSandbox: true` が必要**（サンドボックスがネットワークを遮断する）。
- サンドボックス無効時は `/tmp` が別実体になるため、**取得とパースは同一 Bash 呼び出し内で完結**させる（ファイルを跨いで参照しない）。

## 不採用ソース（再検討しないための記録）
- **e-Stat 地方財政状況調査 API**（`statsCode=00200251`）: 福岡市 `cdArea=40130` で歳入歳出が取れるが **1989〜2018年度のみ（2019以降はDB未整備）**。最新が出せず不採用。
- **総務省 財政状況資料集**（政令市Excel・令和5年度まで）: 最新はあるが Excel。福岡市オープンデータCSVで足りるため不要。
- **税金の使い道マップ**（inshatancountry-jpn-tax-map.com）: 第三者加工・福岡市は2023/2024の2年のみ・再配布許諾不明で不使用。
