# 福岡市 財政・人口データ取得スキル（地方財政状況資料集 Excel）

> **【廃止注記】** このデータを使った自作の `/finance` ページ（`web/src/features/city-finance/`）と取得スクリプトは廃止し、
> トップの導線は外部サイト **「税金の使い道マップ」**（`https://inshatancountry-jpn-tax-map.com/local-tax/?pref=40&entity=401307`）へのリンクに置き換えた。
> 以下は当時の **データ調査記録**（将来、福岡市の財政データを自前で扱う際の参考）として保存している。

福岡市の財政データは **福岡市公式「地方財政状況資料集（各年度決算）」Excel** から取得する。
公式・一次・最新（令和6年度＝2024年度決算まで）・年度別ファイルで、歳入財源別／歳出目的別／総額／人口／財政指標を含む。

> このskillがあれば、データ源の再探索なしにURL・対象シート・抽出ロジックが分かる。

## データ源（年度別Excel）
- 各年度決算ページ: `https://www.city.fukuoka.lg.jp/zaisei/zaisei/shisei/R{N}aramashi.html`（N=令和の年。例 R6=令和6年度＝2024年度決算、2025年9月公表）
- 資料集Excel URL: `https://www.city.fukuoka.lg.jp/zaisei/zaisei/shisei/documents/{N}zaiseijoukyoushiryoushuu.xlsx`
  - 例 令和6: `6zaiseijoukyoushiryoushuu.xlsx` / 令和5: `5...` / 令和2: `2...`（令和2〜6で配置一致を確認済み）
- 1ファイル ≒ 580KB。**HTTPアクセスは User-Agent を付与**（無いと弾かれる場合あり）。

## 対象シートと抽出（読み違い防止が最重要）
**「普通会計の状況」シート**（歳入と歳出が横並びで密集。ラベルベースで抽出する）
- **歳出目的別**: 議会費/総務費/民生費/衛生費/労働費/農林水産業費/商工費/土木費/消防費/教育費/災害復旧費/公債費/諸支出金（13区分）。各ラベルの最初の出現セルの右隣の数値が決算額（千円）。
  - **検証必須**: 13区分の合計＝「歳出合計」と一致すること（令和2〜6で1円まで一致を確認）。一致しなければ抽出ミス。
  - 注意: 「公債費」は目的別と性質別の両ブロックに出る → **最初の出現（目的別）**を採る。
- **歳入財源別**: 地方税/地方譲与税/地方交付税/分担金・負担金/使用料/手数料/国庫支出金/都道府県支出金/財産収入/寄附金/繰入金/繰越金/諸収入/地方債。残り（各種交付金の小項目群）は **歳入総額−主要款合計 ＝「各種交付金等」** に集約（≒4〜7%、依存財源）。

**「総括表」シート**（単一値・ラベルの右側に値）
- 歳入総額 / 歳出総額（千円）、経常収支比率 / 財政力指数 / 実質公債費比率 / 将来負担比率、地方債現在高、各基金残高。
- 住民基本台帳人口: ラベル「令0X.01.01(人)」の右の値。**最新の1月1日**を当該年度の人口として採用。
- 令和6ファイルには **令和6＋令和5の2年分**（BN列/BV列）が入る。

**「データシート」シート**: 実質収支比率・基金残高・1人あたりコスト等の **5年推移（R02〜R06）** がキャッシュ済み。

> 分析表シート（目的別歳出決算分析表 等）は **数式キャッシュ無しで値がNone** になる。実数値は上記「普通会計の状況」「総括表」「データシート」から採ること。

## 福岡市の検証済み実値（令和6年度＝2024）
- 歳入総額 1,131,768,029千円（≒1兆1,318億円）／歳出総額 1,113,379,745千円（≒1兆1,134億円）
- 歳出目的別: 民生費 386,970,614（34.8%）・教育費 188,412,015（16.9%）・商工費 184,894,514・土木費 94,578,736・公債費 97,556,573・総務費 69,280,063・衛生費 61,888,959 …（合計＝歳出合計 ✓）
- 歳入: 地方税 383,742,341（33.9%）・国庫支出金 220,466,235（19.5%）・諸収入 191,472,651・地方交付税 56,351,318・地方債 58,579,000 …
- 住基人口 1,608,140人（令07.01.01）／経常収支比率 93.6%／財政力指数 0.87／将来負担比率 58.8%
- ※この歳入総額は e-Stat 由来の値と完全一致（クロス検証済み）。

## 取得スクリプト
- `scripts/fetch-fukuoka-finance.py`（openpyxl 使用）。令和2〜6の各Excelを取得→ラベルベース抽出→**目的別合計＝歳出合計を検証**→`web/src/features/city-finance/data/fukuoka-finance.json` を生成。
- 実行: `python3 scripts/fetch-fukuoka-finance.py`（要 openpyxl・ネットワーク）。年度更新時に N を足して再実行。
- 出力JSONの単位は千円（`unit: "thousand_yen"`）。UI側で円換算（×1000）。

## 出典・利用
- 出典表記: **「出典: 福岡市オープンデータ（地方財政状況資料集）」**（年度を併記）。福岡市オープンデータの利用条件に従う。一次・公式のため二次利用の懸念は小さい。

## 環境の注意（このリポジトリ／Claude Code）
- 外部HTTP取得は Bash の `dangerouslyDisableSandbox: true` が必要（サンドボックスがネットを遮断）。
- サンドボックス無効時は `/tmp` が別実体になるため、取得とパースは同一Bash内で完結させるか、**worktreeの実パスへ直接書き出す**。

## 不採用ソース（再検討しないための記録）
- **福岡市オープンデータ旧CKAN**（`ckan.open-governmentdata.org`, 旧 `zaiseijoukyou-no-suii`）: ドメインが **NXDOMAIN（廃止）**。
- **移行先 BODIK**（`data.bodik.jp` 組織 `401307`, 495データセット）: 「財政状況の推移」は移行されておらず、税務統計・人口推移のみ。財政内訳は無い。
- **e-Stat 地方財政状況調査 API**（`statsCode=00200251`）: 福岡市は1989〜2018のみ（最新欠落）。
- **税金の使い道マップ**（第三者・2年・許諾不明）。
