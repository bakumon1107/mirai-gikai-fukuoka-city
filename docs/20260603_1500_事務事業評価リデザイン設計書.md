# 事務事業評価 リデザイン設計書

作成日: 2026-06-03

---

## 1. 方針転換の背景

### やめること
- **総合スコア（0〜100点）・グレード（A/B/C/D）の廃止**
  - 様々なケースがあり、単一スコアで横断比較することが困難
  - スコアが低くても理由が異なる（データ未整備 vs 成果悪化 vs 特殊事情）
  - 数値の一人歩きを防ぐ

### やること
- **KPI・予算・効率それぞれの「動き」を分析して表示する**
- 各軸を独立して評価し、分析テキストで説明する
- **分析テキストはルールベースで自動生成**（AI APIは不使用）

---

## 2. 新しい評価構造

### 3つの分析軸

```
① KPI達成状況
  - 各成果指標の達成率（今年度）
  - R5→R6 の実績変化率（改善・悪化・横ばい）

② 予算の動き
  - R5→R6 の歳出変化率
  - R7予算の方向性（増加・減少・維持）

③ 予算効率（KPI/予算）
  - 達成率平均 ÷ 歳出 の R5→R6 変化
  - 解釈テキスト（改善・悪化・横ばい・データ不足）
```

## 4. 分析テキスト生成ロジック

### 4-1. KPI分析テキスト

```typescript
function generateKpiAnalysis(data: JimuJigyoData): string {
  // 主要成果指標（1番目）の実績変化を分析
  // 達成率テキスト（"達成"/"未達成"）も考慮
  // パターン:
  //   改善: "○○は前年比+X%改善しました。達成率は Y%です。"
  //   悪化: "○○は前年比-X%悪化しました。目標に対する達成率はY%です。"
  //   横ばい: "○○は前年度とほぼ同水準です（実績: N）。"
  //   データ不足: "当年度の実績データが未集計です（調査未実施または集計中）。"
  //   目標なし: "数値目標は未設定のため定量的な評価が困難です。行政評価では「達成」とされています。"
}
```

### 4-2. 予算分析テキスト

```typescript
function generateBudgetAnalysis(data: JimuJigyoData, year: string): string {
  // R5→R6 歳出変化率を算出
  // R7予算があれば方向性も言及
  // 財源構成（一般財源/特定財源）への言及
  // パターン:
  //   大幅増（30%超）: "歳出が前年度比+X%と大幅に増加しています。増加の理由と成果への影響に注目が必要です。"
  //   増加: "歳出は前年度比+X%増加しています。"
  //   維持: "歳出は前年度とほぼ同水準（変化率X%以内）です。"
  //   減少: "歳出が前年度比-X%削減されました。"
}
```

### 4-3. 効率分析テキスト

```typescript
function generateEfficiencyAnalysis(data: JimuJigyoData, year: string): string {
  // 達成率平均 / 歳出 の変化率で判定
  // パターン:
  //   大幅改善（10%超）: "予算効率が顕著に改善しています（+X%）。"
  //   改善: "予算効率はやや改善しています（+X%）。"
  //   横ばい: "予算効率はほぼ維持されています（X%）。"
  //   悪化: "予算が増加したにもかかわらず、KPIの改善が限定的なため、コスト効率が悪化しています（-X%）。"
  //   データ不足: "達成率の数値データが不足しているため、効率指標の算出が困難です。"
}
```

## 5. グラフの修正

### 5-1. Y軸を整数値に
```typescript
<YAxis
  allowDecimals={false}
  tickFormatter={(v) => Math.round(v).toLocaleString()}
/>
```

### 5-2. 折れ線の色をやめる
- 緑/赤の色分けを廃止 → 中立色（`var(--color-mirai-text-muted)`）に統一
- 改善/悪化はテキスト分析で示す（グラフで色で示すのではなく）

### 5-3. R7データの正しい表示
- `目標.R7` が JSON に含まれる場合、グラフの3点目として「R7目標」を表示
- `事業費_千円.R7予算` は予算グラフに反映（既存の実装で対応済み）
- **JSONデータ読み取りエラーの修正が前提**（後述）

## 7. 型の変更

### 廃止する型
```typescript
// 以下は廃止
type ScoreBreakdown = { kpiScore, trendScore, transparencyScore, budgetScore }
type ScoreResult = { score, grade, breakdown }
```

### 新しい型
```typescript
type KpiAnalysis = {
  changeRate: number | null;        // R5→R6 変化率（主要指標）
  achievementRate: number | null;   // R6 達成率（%）
  direction: "up" | "down" | "flat" | "unknown";
  text: string;                     // 自動生成テキスト
};

type BudgetAnalysis = {
  changeRate: number | null;        // R5→R6 歳出変化率
  direction: "up" | "down" | "flat" | "unknown";
  text: string;
};

type EfficiencyAnalysis = {
  changeRate: number | null;
  direction: "up" | "down" | "flat" | "unknown";
  text: string;
};

type JimuJigyoAnalysis = {
  kpi: KpiAnalysis;
  budget: BudgetAnalysis;
  efficiency: EfficiencyAnalysis;
};

// JimuJigyoRecord の変更
type JimuJigyoRecord = JimuJigyoData & {
  id: string;
  flags: WatchdogFlag[];
  analysis: JimuJigyoAnalysis;
  // score, grade, breakdown は削除
};
```
