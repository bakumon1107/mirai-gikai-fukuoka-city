# KPI・予算効率分析 改善設計書

作成日: 2026-06-03

---

## 1. 現状の問題点

### 予算スコア（calcBudgetScore）の課題

現在の評価は「予算の変化量」だけを見ている：

```
減少または±5%以内 → 10点（良）
5〜30%増加       →  5点（要注意）
30%超増加         →  0点（悪）
```

**問題:** 予算増加 = 悪、という前提が間違っている。
- 事業拡大や新施策で予算が増えても、KPIが同等以上に改善すれば「コスパ維持・向上」であり問題ない
- 逆に予算が減っても、KPIも同様に悪化していれば「安上がりだが成果なし」

### budget_surge フラグの課題

30%超増加で一律フラグを立てているが、KPI改善を伴う予算増加は自然。
フラグが「問題の誤検知」になっているケースがある。

---

## 2. 新しい評価の考え方

### 基本思想：「コスト効率（KPI/コスト）の変化」で評価する

```
コスト効率 = 主要KPI実績値 ÷ 歳出（千円）

R5効率 = R5実績 ÷ R5歳出
R6効率 = R6実績 ÷ R6歳出

効率変化率 = (R6効率 - R5効率) / R5効率
```

#### 評価パターン

| 予算変化 | KPI変化 | 評価 | 点数案 |
|---------|---------|------|-------|
| 増加 | KPIも比例以上に改善 | ✅ 適正な投資拡大 | 高 |
| 増加 | KPI改善が小さい | ⚠️ 投資対効果が低い | 中 |
| 増加 | KPI悪化 | ❌ 予算増 + 成果悪化 | 低 |
| 安定 | KPI改善 | ✅ 効率化成功 | 高 |
| 安定 | KPI悪化 | ⚠️ 成果悪化 | 低（declining で捕捉） |
| 減少 | KPI維持・改善 | ✅ 効率化成功 | 高 |
| 減少 | KPI悪化 | ⚠️ コスト削減 + 成果低下 | 中（declining で捕捉） |

### ユーザーが指摘した着眼点

> 「コスパも本来は年度が増すと良くなるよね。固定費的にかかり続けるのは微妙。」

→ 事業が成熟するにつれてコスト効率が上がるのが理想。
→ 効率変化率がマイナス（効率悪化）の場合はフラグを立てるべき。

## 3. 設計方針

### 3-1. 予算スコア（calcBudgetScore）の見直し

**新しい評価軸: 「コスト効率変化率」**

```typescript
// 効率変化率で評価
効率変化率 ≥ +10%以上改善  → 10点（コスト効率が顕著に向上）
効率変化率 ≥ 0%（維持）    →  8点（予算増でもKPIが比例改善）
効率変化率 -10%〜0%        →  5点（微減、許容範囲）
効率変化率 -10%未満悪化    →  0点（コスト効率が著しく悪化）
```

**データ不足の場合のフォールバック（KPIデータが数値でない場合）:**
```
予算安定 or 減少 → 8点
予算増加 5〜30%  → 5点
予算増加 30%超   → 2点（警戒）
データなし       → 5点（中立）
```

### 3-2. budget_surge フラグの見直し

**新しい判定: 予算急増かつコスト効率悪化の場合のみフラグ**

```
予算 30%超増加 AND 効率変化率がマイナス → budget_surge フラグ
予算 30%超増加 AND KPI も同等以上改善  → フラグなし（正当な投資拡大）
```

### 3-3. コスト効率表示（詳細ページ）

詳細ページに新セクション「コスト効率」を追加：

```
コスト効率推移
  R5: KPI実績 / R5歳出千円 = ○○/千円
  R6: KPI実績 / R6歳出千円 = ○○/千円
  変化: ↑+X% （コスト効率が改善）
```

## 4. 実装上の注意点

### KPI の方向性問題（解決策: 達成率ベースで統一）

現状、「数値が高い = 良い」前提でコスト効率を計算している。
一部の指標（自転車事故件数、犯罪認知件数など）は「数値が低い = 良い」。

**解決方針: 達成率（%）をベースにすることで方向性を吸収する**

行政が算出する 達成率 を使えば、指標の方向に関係なく正規化できる。
- Higher-is-better: 達成率 = (実績 / 目標) × 100%
- Lower-is-better: 行政側が (目標 / 実績) × 100% で計算しているケースが多い

よってコスト効率 = **達成率（%） ÷ 歳出（千円）** で統一する。

ただし達成率が文字列やハイフンの場合はフォールバックとして実績値を直接使う。

**補助判定: 指標名キーワードによる方向推定（フォールバック時）**

```
lower-is-better キーワード例:
件数 / 発生件数 / 認知件数 / 排出量 / ごみ量 / CO2
→ これらは実績値ではなく (1 / 実績値) で効率を計算
```

### 数値型以外の実績値

「調査未実施」「集計中」など文字列の場合は効率計算不能。
→ フォールバック（予算変化量のみ）を適用

### KPI単位の違い

指標ごとに単位が異なる（%、件数、人数、千円など）。
コスト効率は「単位/千円」となり、**同一事業の年度比較のみに使用**（事業間比較には使わない）。

## 5. スコアリングへの影響

### スコア配分の変更

| 軸 | 旧配点 | 新配点 | 理由 |
|----|--------|--------|------|
| 成果KPI達成 | 40点 | 40点 | 変更なし |
| 改善トレンド | 30点 | 30点 | 変更なし |
| 透明性 | 20点 | **10点** | やや重みが大きすぎた |
| 予算効率 | 10点 | **20点** | コスト効率分析が分析の核心 |
| **合計** | **100点** | **100点** | |

### 予算効率スコア（新ロジック）

```
基本: コスト効率変化率 = (R6効率 - R5効率) / R5効率
      R6効率 = R6達成率(%) / R6歳出(千円)
      R5効率 = R5達成率(%) / R5歳出(千円)

効率変化率 ≥ +10% → 20点（満点: コスト効率が顕著に向上）
効率変化率  0〜+10% → 15点（維持・微改善）
効率変化率 -10〜0% → 10点（微悪化、許容範囲）
効率変化率 -10%未満 →  0点（コスト効率が著しく悪化）

フォールバック（KPI数値が不明の場合）:
予算安定/減少(±5%以内) → 15点
予算増加 5〜30%         → 10点
予算増加 30%超           →  5点
```

## 7. 残る論点

1. **複数 KPI がある場合**: スコア計算は全成果指標の達成率**平均**を使用。詳細ページではKPIごとに個別のコスト効率を表示する。 → **確定**
2. **コスト効率の表示**: 「達成率%/千円」という単位は分かりにくい → **変化率（↑+X%）だけ表示**、絶対値は非表示
3. **予算 0 の事業**: 歳出が 0 または不明 → スコア中立（15点）、効率計算スキップ
