# 議案検索 ユーザビリティ改善（表記ゆれ・0件救済・難易度またぎ）設計

- 作成日: 2026-06-27
- ブランチ: `feat/bill-search-usability`（`feat/bill-search-filters` からスタック）
- 親設計書: `docs/20260626_1500_議案検索機能設計.md`（`docs/bill-search-design` ブランチ）

## 1. 背景

検索 Phase 1（フリーワード）/ Phase 2（フィルタ）に対し、計測導入前でも「確実に起きる失敗」への先行投資として、ユーザビリティ観点の3改善を実装する。

1. **表記ゆれ吸収** — 「すとーかー」で「ストーカー」がヒットしない
2. **0件時の救済** — 「見つかりませんでした」で行き止まりになる
3. **難易度またぎ検索** — 表示難易度と別の難易度にしか無い語が静かに0件になる

## 2. ① 表記ゆれ吸収

### 方式
DB側の正規化カラムは作らず、**アプリ側でクエリのバリエーションを生成**して OR 検索する（マイグレーション不要・最小コスト）。

- `normalizeSearchQuery()`: NFKC 正規化 + trim（全角英数→半角、半角カナ→全角カナ）
- `toHiragana()` / `toKatakana()`: かな相互変換（コードポイント ±0x60）
- `buildSearchQueryVariants()`: [原文, ひらがな化, カタカナ化] の重複排除リスト

実装: `web/src/features/bill-search/shared/utils/normalize-search-query.ts`（純粋関数・テスト付き）

### 検索条件の構築
リポジトリでバリエーションごとに `title.ilike` / `summary.ilike` 条件を展開して `or()` に渡す（最大 3変種 × 2カラム = 6条件）。各変種はサニタイズ（構造文字除去）+ ILIKE エスケープ後に埋め込む。

## 3. ③ 難易度またぎ検索

### 課題
Phase 1 は `bill_contents!inner` + 現在難易度フィルタの上で `or(ilike)` していたため、**現在の難易度のテキストしか検索対象にならない**。「やさしい」表示中のユーザーが「詳しい」版にしか無い語で検索すると、理由が見えないまま0件になる。

### 方式（2段クエリ）
1. **マッチ判定**: `bill_contents` を難易度を問わず直接検索し、マッチした `bill_id` 集合を得る
2. **表示データ取得**: `bills` + 現在難易度の `bill_contents!inner` を `id in (マッチ集合)` で取得

表示は常に現在難易度のコンテンツなので、UI 側の変更は不要。`referencedTable` 付き `or()` も不要になり、クエリ構造が単純化された。

> スケール時の注意: `in()` に渡す id が長大になったら pg_trgm / RPC へ移行する（親設計書 §10.3）。

## 4. ② 0件時の救済

0件表示を行き止まりにせず、3種類の「次の一手」を提示する。

| 救済 | 発動条件 | 実装 |
| --- | --- | --- |
| **フィルタ緩和ヒント** | 0件 & フィルタあり & 有効なキーワード | フィルタなしで再検索し、N>0 なら「絞り込みを解除するとN件見つかります」リンク（`routes.search(q)`）を表示 |
| **AIチャット橋渡し** | — | **保留（ユーザー判断で一旦封印）**。詳細は下記 |
| **キーワード提案** | 0件時は常時 | `SUGGESTED_KEYWORDS`（shared/constants に移動して SearchBox と共用）をリンクチップで表示 |

### AIチャット橋渡し（保留）

0件時に既存 `ChatButton` の `openWithText()` ref を再利用し、検索語をそのままチャットへ引き継ぐ `SearchChatBridge` を一度実装したが、**ユーザー判断により一旦封印（コード削除）**した。復元する場合はコミット `16348e4b` の `search-chat-bridge.tsx` と `page.tsx` の差分を参照。セマンティック検索（親設計書 §10.4）導入前の安価な代替という位置づけは変わらないため、再開判断の際はチャットのコスト（AI Gateway 課金・レート制限）と検索起点の流入量を確認してから。
