## 1. 実装内容

親設計書 §10.1 の Phase 1（MVP・マイグレーション不要）を実装した。

| 項目 | ファイル |
| --- | --- |
| `/search` ページ（薄いラッパー） | `web/src/app/(main)/search/page.tsx` |
| 検索フォーム（サジェストキーワード付き） | `web/src/features/bill-search/client/components/search-box.tsx` |
| 結果表示（既存 BillCard 再利用） | `web/src/features/bill-search/server/components/search-results.tsx` |
| ローダー（難易度Cookie対応・キャッシュなし） | `web/src/features/bill-search/server/loaders/search-bills.ts` |

| ヘッダー検索導線 | `web/src/components/header/header-client.tsx` |

検索方式は PostgREST `.or(title.ilike, summary.ilike)`（親設計書 §4 の判断どおり）。`unstable_cache` はフリーワードのカーディナリティが高いため不使用。

## 2. セルフレビュー結果（/code-review high・修正済み）

| 深刻度 | 指摘 | 対応 |
| --- | --- | --- |
| 高 | `?q=a&q=b` で `q` が配列になり `q.trim()` で500クラッシュ | `typeof q === "string"` ガードで修正 |
| 中 | ILIKE ワイルドカード `% _ \` 未エスケープ（`%%` で全件マッチ＝最小文字数バイパス） | `escapeIlikePattern()` を追加し埋め込み直前に適用 |
| 低 | 最小文字数チェックがサニタイズ前の文字列長で判定されていた | サニタイズ後の長さで判定に変更 |
| 低 | `/search` で難易度セレクタ非表示（検索結果は難易度Cookie依存なのに変更できない） | ヘッダーの表示条件に `/search` を追加（`isMainPage` は変更せずレイアウト波及を回避） |
| 規約 | ローカル検証用 `supabase/config.toml` 変更が作業ツリーに混在 | コミットから除外（ローカル保持のみ） |
