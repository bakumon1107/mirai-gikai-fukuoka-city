# 議案検索 AIインタビューフィルタ設計

- 作成日: 2026-06-27
- ブランチ: `feat/bill-search-interview-filter`（`feat/bill-search-usability` からスタック）
- 親設計書: `docs/20260627_1610_議案検索フィルタ設計.md`（`feat/bill-search-filters` ブランチ）

## 1. 背景

既存フィルタ（会期・カテゴリ・ステータス）に加え、「AIインタビュー受付中の議案だけを探したい」というニーズに対応する。議案カードには既に「AIインタビュー受付中」バッジが表示されており（`hasPublicInterview`）、その判定と同じ条件で絞り込めるようにする。

## 2. 仕様

- **URLパラメータ**: `interview=1`（トグル・未指定でフィルタなし）
- **判定条件**: `interview_configs.status = 'public'` の設定を持つ議案（バッジ表示と同一条件）
- **UI**: フィルタ行の末尾にトグルチップ「AIインタビュー受付中」（`aria-pressed` 付き Button）。ON時は primary 塗り
- 他フィルタ・キーワードとAND条件で併用可能。「絞り込みを解除」でOFFになる

## 3. 実装

- `BillSearchFilters.hasPublicInterview?: boolean` を追加し、`findPublishedBillsBySearch` 内で `interview_configs` から対象 `bill_id` を先に解決して `.in("id", ids)`（タグフィルタと同じ2段クエリ方式）
- `SearchFilterParams.interview?: string` / `routes.search()` の filters に `interview` を追加
- `search-filters.tsx` にトグルチップ、`search-box.tsx` はキーワード変更時に `interview` パラメータを維持
