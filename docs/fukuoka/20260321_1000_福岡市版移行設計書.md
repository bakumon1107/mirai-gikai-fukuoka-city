## 1. 概要

川崎市議会版（`kawasaki/develop` ブランチ）をベースに、福岡市議会向けへ移行する。
変更対象は主に `site.config.ts` 2ファイル・シードデータ・画像素材・Langfuseプロンプトに限定され、アプリケーションロジックは原則そのまま流用する。

### ブランチ戦略

```
kawasaki/develop   ← fork元（川崎市議会版）
fukuoka-city/develop  ← 福岡市版の統合ブランチ（このリポジトリのベースブランチ）
    └── feat/xxx   ← 各作業ブランチ → fukuoka-city/develop へPR
```

## 6. Langfuse プロンプト設定

AIチャット・インタビュー機能のプロンプトを福岡市議会向けに調整する。

### 変更が必要なプロンプト

| プロンプト名 | 変更内容 |
|---|---|
| `top-chat-system` | 地名・議会名を福岡市議会向けに変更 |
| `bill-chat-system-normal` | 同上 |
| `bill-chat-system-easy` | 同上 |
| `bill-chat-system-hard` | 同上 |
| インタビュー用プロンプト各種 | 同上 |

**手順:**
1. Langfuseプロジェクトを新規作成し環境変数を設定
2. 川崎版のプロンプトを複製して地名・議会名を差し替え
3. Admin管理画面でテスト動作を確認

---

## 7. AI情報収集設定

`admin/` の AI情報収集（Claude CLI）は `CLAUDE_CLI_PATH` の設定のみで動作する。
福岡市議会の議案URLを `councilBillsDetailUrl` に設定すれば、情報収集プロンプトが自動的に福岡市向けになる。
