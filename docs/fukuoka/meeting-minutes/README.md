# 福岡市議会 会議録アーカイブ

`general_questions` / `bill_discussions` の取り込み元となった会議録の全文テキストを、会期ごとに保存している。

## 何のために残すか

再パースのためではない（質問者ごとの本文は `general_questions.raw_text` としてDBに入っている）。主な用途は次の2つ。

1. **パーサの検証** — 取り込み結果に不審な箇所があったとき、原本と突き合わせて「原文どおりか、変換処理の欠落か」を判別する
2. **取り込み範囲外の情報の保全** — `raw_text` は登壇行以降の質疑応答のみで、議事日程・出席議員名簿・議長の進行・討論採決の日は含まれない

速報版（`gikai.city.fukuoka.lg.jp/result/prompt/`）は正式な会議録が作成されると差し替えられるため、その時点のスナップショットはここにしか残らない。

## ファイル名

```
<会期名>/<YYYY-MM-DD>_<N>日目.txt
```

`N` は会議録上の「第N日」。一般質問以外の日（議案質疑・討論採決）も、その会期分を取得していれば併せて置く。

## 取得方法

`update-general-questions` スキルを参照。取得元は2系統ある。

| 取得元 | 位置づけ |
| --- | --- |
| 会議録検索システム（`city.fukuoka.fukuoka.dbsr.jp`） | 正式版。URLに一時IDを含むため、一覧のページ送りから辿る必要がある |
| 会議録速報版（`gikai.city.fukuoka.lg.jp/result/prompt/`） | 暫定版。正式版が出るまでの間に公開される。誤植・表記ゆれを含む |

## 表記の正規化

原文をそのまま保存するのが原則。ただし取得元による表記の差だけは、既存データと突き合わせられるよう次の2点のみ揃えている。

| 対象 | 変換 | 理由 |
| --- | --- | --- |
| 発言者行の先頭記号 | `○`（U+25CB）→ `◯`（U+25EF） | 速報版は U+25CB を使う。UI の逐語録表示（`raw-transcript-view.tsx`）が `◯` で発言を分割している |
| 市長名の異体字 | `髙島` → `高島` | 速報版は `髙島`、正式版と既存DBは `高島` |

**上記以外の異体字・誤植・表記ゆれは直さない。** 一次資料としての同一性が失われ、正式版と突き合わせる際に原本と加筆の区別がつかなくなるため。

> 異体字の置換は対象を限定すること。過去に `髙 → 高` の一括置換で、議会事務局次長「髙着一孝」の氏名まで変えてしまった例がある。

速報版に実在する表記の例（いずれも修正しない）:

- `外関係職員`（「その他関係職員」の脱字と思われる）
- `施設管理者、たは市職員`（「または」の脱字）
- `出席議員（60名）` と名簿の実数（59名）の不一致
