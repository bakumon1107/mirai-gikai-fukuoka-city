## 概要

## 1. チャット機能の一時無効化

### 背景

OpenAI API キーが未設定のため、チャット機能を有効のまま公開するとエラーが発生する。

### 対応

`web/src/config/site.config.ts` で以下を変更:

```ts
features: {
  aiChat: false,       // true → false
  aiInterview: false,  // true → false
}
```

### 再有効化手順

1. Vercel AI Gateway でプロバイダーキー（OpenAI 等）を登録
2. `AI_GATEWAY_API_KEY` を Vercel 環境変数に設定
3. `LANGFUSE_PUBLIC_KEY` / `LANGFUSE_SECRET_KEY` / `LANGFUSE_BASE_URL` を設定
4. `site.config.ts` で `aiChat: true` に戻す
5. Vercel に再デプロイ

## 2. ヘッダのサイト名改行修正

### 問題

「みらい議会ー福岡市版」の末尾「版」がデスクトップメニューで改行されていた。
川崎版より1文字多く（「福岡市版」vs「川崎版」）、36px × letterSpacing 0.1em の幅が親コンテナを超えていた。

### 対応

`web/src/components/layouts/desktop-menu/logo.tsx` の h1 に `whiteSpace: "nowrap"` を追加:

```tsx
style={{
  fontSize: "36px",
  lineHeight: "1em",
  letterSpacing: "0.1em",
  whiteSpace: "nowrap",  // 追加
}}
```

## 3. 閉会ロジックの修正（Cloud Supabase データ修正）

### 問題

Cloud Supabase の `council_sessions` テーブルで r8-1 会期の `end_date` が `null` になっており、
`getCurrentCouncilSession` の SQL 条件 `end_date IS NULL OR end_date >= targetDate` により
閉会後も「開会中」と表示されていた。

### 対応

Cloud Supabase の REST API 経由で直接更新:

```bash
curl -X PATCH "https://<project-ref>.supabase.co/rest/v1/council_sessions?slug=eq.r8-1" \
  -H "Authorization: Bearer <service_role_key>" \
  -H "Content-Type: application/json" \
  -d '{"end_date": "2026-03-27"}'
```

### 今後の運用

新しい会期を登録する際は `end_date` を必ず設定すること。
マスターデータのシード (`packages/seed/fukuoka/`) に含まれる会期データに `end_date` が含まれているかを確認する。

## 4. 無所属議員の個人名表示

### 問題

PDF からスクレイプした採決データでは、無所属議員は会派「無所属」として一括集計されていた。
これを個人名で表示するよう UI を変更。

### 福岡市議会の無所属議員（2026年3月時点）

出典: https://gikai.city.fukuoka.lg.jp/member/party/

| 氏名 |
|------|
| あべ ひでき |
| 新開 ゆうじ |
| 木村 てつあき |
| 森 あやこ |
| 川口 浩 |

### 対応

`web/src/features/bills/client/components/bill-detail/faction-stance-card.tsx` に展開ロジックを追加:

```ts
const MUSHOZOKU_MEMBERS = [
  "あべ ひでき",
  "新開 ゆうじ",
  "木村 てつあき",
  "森 あやこ",
  "川口 浩",
];

function expandStances(stances: FactionStance[]): FactionStance[] {
  return stances.flatMap((stance) => {
    if (stance.faction.display_name !== "無所属") return [stance];
    return MUSHOZOKU_MEMBERS.map((name, i) => ({
      ...stance,
      id: `${stance.id}-${i}`,
      faction: { ...stance.faction, display_name: name },
    }));
  });
}
```

### 制約・注意事項

- スクレイプデータは無所属全体の集計票（全員同じ投票として記録）のため、個人別の投票記録は持っていない
- 表示上は全員が同じ採決（賛成/反対）で表示される
- 議員名簿が変わった場合（改選・辞職等）は `MUSHOZOKU_MEMBERS` の更新が必要
