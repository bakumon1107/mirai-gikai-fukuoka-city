# 一般質問ページ オーバービュー（3行サマリー＋テーマ別アコーディオン）設計

## 背景・課題
セッション一覧ページ `/sessions/[slug]/questions`（テーマ別ビュー）は、代表質疑を含む定例会では情報量が過大になる。

- r8-1（令和8年第1回定例会）は **22議員・110トピック・9カテゴリ**。
- 9カテゴリのセクションが常時開いた縦長ページで、市民が入口で圧倒される（てんこもり）。

## 目的
ファーストビューを「3行のあらすじ＋テーマの目次」に圧縮し、関心のあるテーマだけ展開して読める progressive disclosure 型に変える。

## 決定事項（2026-06-25 ユーザー確認済み）
1. **レイアウト**: テーマ別アコーディオン一覧。各テーマ行はアイコン＋ラベル＋件数。**初期状態はすべて折りたたみ**。開くと中に既存の詳細カードを表示（テーマ単位の3行ダイジェストは作らない）。
2. **3行サマリーの粒度**: **セッション全体に1つ**だけ（「今回の一般質問、どんな話があった？」）。
3. **生成方法**: AI生成＋DB保存。投入前にユーザー確認（AI生成コンテンツ更新ルール準拠）。
4. **保存先**: 専用テーブル `general_question_overviews`（feature がデータを持つ既存パターンに整合。`council_sessions` は川崎市と共有のため列追加を避ける）。

## 画面設計
```
令和8年第1回定例会の一般質問
📌 どんな話があった？（今回の3行まとめ）
 1. …  2. …  3. …                         ← セッション3行（general_question_overviews）
─────────────────────────────────────────
▸ 🍼 子育て・教育   40件   [＋]            ← テーマ・アコーディオン（初期=全閉）
▸ 🩺 健康・医療     23件   [＋]
▾ 🏛 行財政・経済   12件   [－]            ← 開くと中に既存カード
    [カード][カード]…
… 9テーマ
```
- 3行が未生成（null）なら3行ブロックは非表示（グレースフル）。
- 補助操作として「すべて開く／閉じる」を用意。
- カテゴリの並び順・アイコン・色は既存 `buildTopicGroups` / `CATEGORY_STYLE` を踏襲。

## データモデル
新テーブル `general_question_overviews`（セッション1:1）。

```sql
create table general_question_overviews (
  council_session_id uuid primary key references council_sessions(id) on delete cascade,
  lines text[] not null,            -- 3行（要素数は3を想定、UI側は最大3表示）
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);
alter table general_question_overviews enable row level security;
-- ポリシーは定義しない（デフォルト全拒否）。アクセスは createAdminClient() 経由。
```
- RLS有効・ポリシーなし（プロジェクト規約どおり）。読み取りは Service Role の loader 経由。

## 生成パイプライン
- 入力: 当該セッションの全 `general_questions.topics`（title / question_summary / answer_summary）。
- 出力: 市民向けの3行（各行1文・横断的な「今回の大きな話題」）。文体は topics と同基準（やさしく、断定しすぎない）。
- フロー: 生成 → **ユーザーに提示して確認** → REST で `general_question_overviews` に upsert。
- 対象: 既存公開セッション r8-1・r7-5。
- 本番DDL適用: Supabase Management API（`SUPABASE_ACCESS_TOKEN`）でプロドにテーブル作成。ローカルは migration で反映し `db:types:gen`。

## コンポーネント設計
```
sessions/[slug]/questions/page.tsx (Server)
  ├─ getGeneralQuestionsBySession()
  ├─ getGeneralQuestionOverviewBySession()   ← 新規 loader
  └─ <SessionTopicsView questions overview />  (Server)
       ├─ buildTopicGroups(questions)          ← 既存（サーバーで分類確定）
       └─ <SessionQuestionsOverview groups overviewLines />  ← 新規 Client
            ├─ 3行ブロック（overviewLines）
            └─ アコーディオン（groups）→ 開くと <TopicCard/>（共有化して再利用）
```
- `TopicCard` を `session-topics-view.tsx` から切り出して共有（Server/Client 両用の純表示）。
- 開閉状態は Client state（`useState`）。SEO/初期表示のため全カードはDOMに出し、CSSで開閉してもよい（アクセシビリティ: `<details>`/aria）。
