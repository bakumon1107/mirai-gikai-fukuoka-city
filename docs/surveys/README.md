# 自治体議会サイト 適合度調査レポート

fork を検討している自治体について、**みらい議会のどの機能まで作れるか**を
調べた結果を置く場所です。`<YYYYMMDD>_<自治体名>調査.md` の形式で保存します。

> **ここはスキルの既定の出力先ではありません。**
> `/council-survey` はレポートをリポジトリ外に出力し、コミットしません。
> 複数の自治体を調査している事実が履歴に残るのを避けるためです。
>
> fork 先が**自地域の**調査結果を記録として残す場合に、ここへ手で保存してください。
> その場合も、他地域の調査結果は置かないこと。

判定軸・Tier の定義・レポートテンプレートは
[.claude/skills/council-survey/SKILL.md](../../.claude/skills/council-survey/SKILL.md) にあります。

> レポートは調査時点のスナップショットです。議会サイトは改修されるため、
> 着手が調査から時間が空いている場合は再調査してください。
> 特に軸14（URL安定性）は、2時点を比較しないと判定できません。
