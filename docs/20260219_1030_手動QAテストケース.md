# 手動 QA テストケース

**対象:** 地方議会版を fork して公開する前の動作確認
**使い方:** このファイルを fork 先リポジトリにコピーし、`結果` 欄を埋めながら実施する

> **前提:** ローカル環境が起動済みであること。
> 起動手順は [docs/20260219_1000_ローカル環境起動手順.md](20260219_1000_ローカル環境起動手順.md) を参照。
>
> 表中の記号は以下の設定値に読み替えること。
> - `{サイト名}` = `siteConfig.siteName`（例: みらい議会＠サンプル市）
> - `{議会名}` = `siteConfig.councilName`（例: サンプル市議会）
> - `{住民呼称}` = `siteConfig.residentTerm`（例: 市民 / 県民）
> - `{定例会スラッグ}` = シードまたは実データの定例会 slug（例: r7-4）

### 既知の注意点

- インタビューチャット API (`/api/interview/chat`) は `experimental_useObject` フックを使うため、
  curl ではストリーミング応答を受信できない（"Empty reply from server"）。
  セッション作成の成否は `interview_sessions` テーブルで確認し、正常系はブラウザで目視確認すること。
- シードデータは会派見解が1会派分しか登録されていないため、
  A-3-4（複数会派の見解表示）は実データ投入後に再確認すること。
