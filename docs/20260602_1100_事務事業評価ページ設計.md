作成日: 2026-06-02

## 1. 概要・目的

### 背景
福岡市が公開する「事務事業マネジメントシート」をもとに、**監視者（市民・議員）の視点**で客観的に評価・可視化するページ。

行政は「うまくいっている」書き方をしがちであるため、以下の観点で**逆張り評価**を提示する：

- 目標値の設定が甘くないか（達成率が高すぎないか）
- 成果指標が曖昧・未設定ではないか
- 予算増加に見合う成果が出ているか
- 実績が悪化しているのに事業継続されていないか

### ページ名
`/jimu-jigyo` ─ 「事務事業評価」

## 4. スコアリング設計（監視者スコア）

### 基本思想
「行政が言う達成率をそのまま信じない」。目標値の妥当性・透明性・トレンドを加味する。

### スコア計算式（0〜100点）

```
総合スコア = 成果指標スコア(40) + トレンドスコア(30) + 透明性スコア(20) + 予算効率スコア(10)
```

#### ① 成果指標スコア（0〜40点）

```
成果指標ごとに達成率（実績/目標）を計算し、補正した上で平均する。

補正ルール：
- 達成率 100%超: min(達成率, 120%) で頭打ち
  ※ 150%超の場合は「目標値が低すぎる」フラグを立てる
- 目標値未設定: 20点（暫定）
- 実績値「集計中」「調査未実施」: 10点（不透明ペナルティ）

補正後達成率の平均 × 0.4 × 100 = 最大40点
```

#### ② トレンドスコア（0〜30点）

```
R5実績 → R6実績 の変化率（成果指標の主要1指標）

変化率 = (R6実績 - R5実績) / R5実績

変化率 +10%以上:  30点
変化率 0〜+10%:   20点
変化率 -10%〜0:   10点
変化率 -10%未満:   0点（フラグ: declining）
```

#### ③ 透明性スコア（0〜20点）

```
ペナルティ方式：20点からスタートして減点

- 成果指標が1つ以上「目標値未設定」: -5点
- 成果指標の主要KPIが「調査未実施」「集計中」: -5点
- 最終年度が「R年度」（未定）: -3点
- 達成率列に「─」「設定なし」が2つ以上: -5点
- ロジックモデル結果アウトカムとKPIの対応が弱い（テキスト類似度低）: -5点
```

#### ④ 予算効率スコア（0〜10点）

```
R5決算 → R6決算 の変化率（歳出）

減少または±5%以内:  10点
5〜30%増:            5点
30%超増:              0点（フラグ: budget_surge）

例外: 予算急増でも成果指標が明確に改善していれば +5点補正
```

### グレード定義

| グレード | スコア | 色 | 意味 |
|---------|--------|-----|------|
| A | 80〜100 | 🟢 緑 | 良好 ─ 成果・透明性ともに高い |
| B | 60〜79  | 🔵 青 | 概ね良好 ─ 一部課題あり |
| C | 40〜59  | 🟡 黄 | 要注目 ─ 複数の懸念点あり |
| D | 0〜39   | 🔴 赤 | 要改善 ─ 成果不明確・悪化傾向 |

## 5. 監視者フラグ（Watchdog Flags）

カードに表示する警告アイコン。複数付与可能。

| フラグ | 表示 | 判定条件 |
|--------|------|---------|
| `low_target` | 🎯 目標が低すぎる | 達成率が150%超の指標が1つ以上 |
| `missing_kpi` | 📊 KPI未設定 | 成果指標の目標値が「設定なし」 |
| `budget_surge` | 💰 予算急増 | R5→R6で歳出30%超増加 |
| `declining` | 📉 実績悪化 | R5→R6で主要指標が10%超減少 |
| `vague_goal` | ❓ 終了基準不明 | 最終年度が「R年度」（未定） |
| `no_data` | 🔒 データ未集計 | 実績値が「集計中」「調査未実施」 |

### フラグのツールチップ

各フラグアイコンはホバー（PC）またはタップ（SP）でツールチップを表示する。  
ツールチップには **① 判定理由** と **② この事業での具体的な数値** を両方示す。

```
🎯 目標が低すぎる
┌──────────────────────────────────────────┐
│ 判定理由                                  │
│ 達成率が150%を超えている指標があります。   │
│ 目標値の設定が実態に対して甘い可能性が    │
│ あります。                                │
│                                          │
│ この事業での数値                          │
│ 「ロゴマークの掲出箇所数」               │
│ 目標:1,000 → 実績:7,566（達成率756%）    │
└──────────────────────────────────────────┘
```

ツールチップの末尾に「[計算方法を詳しく見る →]」リンクを置き、`/jimu-jigyo/about-score#low-target` にアンカーリンクする。

## 11. スコアリング詳細ロジック（`score.ts`）

```ts
// 成果指標1件あたりのスコア計算
function calcKpiItemScore(kpi: KpiItem): number {
  const { target, actual } = kpi;
  
  if (actual === null || actual === "集計中" || actual === "調査未実施") return 0.1; // 不透明ペナルティ
  if (target === null || target === "設定なし") return 0.5;                         // 目標不明
  
  const rate = actual / target;
  
  if (rate >= 1.5) return 0.8;   // 達成率150%超 → 目標が低すぎる（フラグあり）
  if (rate >= 1.0) return 1.0;   // 達成
  if (rate >= 0.8) return 0.7;   // 概ね達成
  if (rate >= 0.6) return 0.4;   // 未達
  return 0.1;                    // 大幅未達
}

export function calcScore(data: JimuJigyoData): ScoreResult {
  const kpiScore = calcKpiScore(data.指標.成果指標) * 40;
  const trendScore = calcTrendScore(data.指標) * 30;
  const transparencyScore = calcTransparencyScore(data) * 20;
  const budgetScore = calcBudgetScore(data.事業費_千円) * 10;
  
  const total = kpiScore + trendScore + transparencyScore + budgetScore;
  
  return {
    score: Math.round(total),
    grade: total >= 80 ? "A" : total >= 60 ? "B" : total >= 40 ? "C" : "D",
    breakdown: { kpiScore, trendScore, transparencyScore, budgetScore },
  };
}
```

## 12. 評価ロジック説明ページ設計（`/jimu-jigyo/about-score`）

ユーザーがスコアの根拠を確認できる静的ページ。  
「なぜこのスコアなのか」を一般市民にも読めるレベルで説明する。

### 目的・位置づけ

- スコアに疑問を持ったユーザーが「このスコアは信頼できるのか」を判断できるようにする
- 一覧ページのリンク・詳細ページのスコア内訳・各フラグのツールチップすべてここにリンクする
- ページ自体はサーバーコンポーネントのStatic（頻繁に変わらないため）

### ページレイアウト

```

│ ← 事務事業評価一覧に戻る                            │

│ スコアとは何か                                      │
│ このページでは、福岡市が公開する「事務事業            │
│ マネジメントシート」（令和6年度実施分）をもとに、    │
│ 行政の自己評価ではなく市民の視点から4つの軸で        │
│ 客観的な評価スコア（0〜100点）を算出しています。     │
│                                                     │
│ ⚠️ 注意: このスコアはあくまで公開データをもとに      │
│ した参考値です。事業の優劣を断定するものでは         │
│ ありません。                                         │
│                                                     │
│ ─────────────────────────────────────────────────  │
│                                                     │
│ 4つの評価軸                                         │
│                                                     │
│ [横並びカード×4]                                    │
│ ┌───────────┐ ┌───────────┐ ┌───────────┐ ┌─────────┐ │
│ │成果KPI     │ │改善トレンド│ │透明性     │ │予算効率 │ │
│ │達成 (40点) │ │(30点)     │ │(20点)     │ │(10点)   │ │
│ └───────────┘ └───────────┘ └───────────┘ └─────────┘ │
│                                                     │
│ ─────────────────────────────────────────────────  │
│                                                     │
│ 軸①: 成果KPI達成（最大40点）              id="kpi" │
│                                                     │
│ 行政が設定した成果指標の達成率（実績÷目標）を         │
│ 評価します。ただし、達成率が極端に高い場合は          │
│ 「目標の設定が甘い」サインとみなし、点数を抑えます。  │
│                                                     │
│ [計算式テーブル]                                    │
│ ┌──────────────────────┬────────────┐            │
│ │ 達成率               │ 点数換算   │            │
│ ├──────────────────────┼────────────┤            │
│ │ 150%超              │ 0.8点      │            │
│ │ 100〜150%           │ 1.0点 (満点)│            │
│ │ 80〜100%            │ 0.7点      │            │
│ │ 60〜80%             │ 0.4点      │            │
│ │ 60%未満             │ 0.1点      │            │
│ │ 目標値なし          │ 0.5点 (暫定)│            │
│ │ 実績値「集計中」等   │ 0.1点      │            │
│ └──────────────────────┴────────────┘            │
│ ※成果指標が複数ある場合は平均値を使用               │
│                                                     │
│ 【なぜ150%超を満点にしないのか】                    │
│ 達成率が150%を超えている場合、目標値が実態に対して    │
│ 低すぎる可能性があります。達成が容易な目標を設定して  │
│ 「達成できた」と報告することは、税金の適切な執行を    │
│ 判断する材料として不適切です。そのため達成率の上限を  │
│ 150%として扱います。                                │
│                                                     │
│ ─────────────────────────────────────────────────  │
│                                                     │
│ 軸②: 改善トレンド（最大30点）          id="trend" │
│                                                     │
│ 令和5年度の実績 → 令和6年度の実績が                 │
│ 改善しているかを評価します。                         │
│                                                     │
│ [計算式テーブル]                                    │
│ ┌──────────────────────┬────────────┐            │
│ │ R5→R6変化率           │ 得点       │            │
│ ├──────────────────────┼────────────┤            │
│ │ +10%以上改善          │ 30点 (満点) │            │
│ │ 0〜+10%改善           │ 20点       │            │
│ │ -10〜0%（微減）       │ 10点       │            │
│ │ -10%超悪化            │  0点       │            │
│ └──────────────────────┴────────────┘            │
│                                                     │
│ ─────────────────────────────────────────────────  │
│                                                     │
│ 軸③: 透明性（最大20点）      id="transparency"    │
│                                                     │
│ 成果指標の目標値が設定されているか、データが           │
│ 公開されているか、いつ事業を終了するかが              │
│ 明確かを評価します。減点方式です。                   │
│                                                     │
│ [減点テーブル]                                      │
│ ┌────────────────────────────────┬───────┐       │
│ │ 減点条件                        │ 減点  │       │
│ ├────────────────────────────────┼───────┤       │
│ │ 成果指標に目標値未設定が1件以上  │ -5点  │       │
│ │ 主要KPIが「調査未実施」「集計中」 │ -5点  │       │
│ │ 最終年度が「R年度」（未定）      │ -3点  │       │
│ │ 達成率欄が「─」等が2件以上      │ -5点  │       │
│ └────────────────────────────────┴───────┘       │
│                                                     │
│ ─────────────────────────────────────────────────  │
│                                                     │
│ 軸④: 予算効率（最大10点）       id="budget"       │
│                                                     │
│ 前年度（令和5年度）から令和6年度にかけて              │
│ 歳出がどう変化したかを評価します。                   │
│                                                     │
│ [計算式テーブル]                                    │
│ ┌────────────────────────────────┬───────┐       │
│ │ 歳出変化率（R5→R6）             │ 得点  │       │
│ ├────────────────────────────────┼───────┤       │
│ │ 減少または±5%以内               │ 10点  │       │
│ │ 5〜30%増加                      │  5点  │       │
│ │ 30%超増加                       │  0点  │       │
│ └────────────────────────────────┴───────┘       │
│                                                     │
│ ─────────────────────────────────────────────────  │
│                                                     │
│ グレード定義                          id="grade"   │
│                                                     │
│ ┌────┬───────┬──────────────────────────────────┐  │
│ │ A  │80〜100│成果・透明性ともに高い              │  │
│ │ B  │60〜79 │概ね良好、一部課題あり              │  │
│ │ C  │40〜59 │複数の懸念点あり、要注目            │  │
│ │ D  │ 0〜39 │成果不明確・悪化傾向、要改善        │  │
│ └────┴───────┴──────────────────────────────────┘  │
│                                                     │
│ ─────────────────────────────────────────────────  │
│                                                     │
│ 監視者フラグ一覧               id="flags"         │
│                                                     │
│ 🎯 目標が低すぎる          id="low-target"        │
│ 達成率が150%超の指標が1つでもある場合に表示。        │
│ 行政が容易に達成できる目標を設定している可能性が      │
│ あります。                                          │
│                                                     │
│ 📊 KPI未設定               id="missing-kpi"       │
│ 成果指標の目標値が「設定なし」となっている場合。      │
│ 目標がなければ達成できたかどうかの判断が難しく、      │
│ 事業効果の検証が困難です。                          │
│                                                     │
│ 💰 予算急増                id="budget-surge"      │
│ 前年度比で歳出が30%超増加している場合。              │
│ 増加の理由と、それに見合う成果改善があるかを          │
│ 確認することを推奨します。                          │
│                                                     │
│ 📉 実績悪化                id="declining"         │
│ 主要な成果指標がR5→R6で10%超減少している場合。       │
│                                                     │
│ ❓ 終了基準不明             id="vague-goal"        │
│ 最終年度が「R年度（未定）」となっている場合。         │
│ いつまで続けるのか、どうなれば終わるのかが            │
│ 不明確な事業です。                                  │
│                                                     │
│ 🔒 データ未集計             id="no-data"           │
│ 実績値が「集計中」や「調査未実施」となっている場合。  │
│ 現時点では評価に必要なデータが揃っていません。        │
│                                                     │
```

### 設計上のポイント

- **全ページから参照可能**: 一覧ページのヘッダー・詳細ページのスコア内訳・各フラグのツールチップ末尾、それぞれからアンカーリンクで直接該当セクションに飛ぶ
- **アンカーリンク対応**: `#kpi` `#trend` `#transparency` `#budget` `#grade` `#flags` `#low-target` 等のフラグIDで直リンク可能
- **数式ではなく言葉で説明**: 一般市民が読めるよう、コードや数式は使わずテーブルと文章で説明する
- **Static生成**: ロジックが変わらない限り更新不要なのでSSGで配信

## 13. 実装上の注意点（再掲）

### データの制約
- 現在のJSONは **令和6年度の1年分のみ**。比較は R5実績 vs R6実績 のみ可能。
- 指標によっては R5目標が設定されていないケースがある。
- 単位が指標によって異なる（%、件数、人数、千円など）ので正規化して比較。

### 監視者視点の注意書き
ページ上部に以下を表示：

> ⚠️ このページは市民・議員の視点から、行政の自己評価ではなく**客観的な指標達成状況**を可視化したものです。  
> スコアは公開データをもとに算出した参考値であり、事業の優劣を断定するものではありません。

### パフォーマンス
- JSON読み込みはビルド時（Static Generation）または `cache: "force-cache"` で対応。
- カード一覧は初期表示20件、スクロールで追加読み込み（intersection observer）。

## 15. 未解決の論点

1. **スコア根拠の開示方法**: スコア算出ロジックをUIでどこまで説明するか
2. **達成率150%問題**: 単に計算が難しかっただけの場合もあるので、フラグの説明文を慎重に
3. **予算効率の判定**: 事業立ち上げ期は予算増が当然のケースもある（開始年度を考慮するか）
4. **「R年度」の扱い**: 終了条件未定はペナルティにすべきか議論が分かれる
